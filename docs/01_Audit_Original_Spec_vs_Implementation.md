## Критические ошибки (могут привести к неверным ответам / вреду)

1. **⚠️→P0 Утечка тенанта в `SqliteHybridStore` (dense-ветка).** Доказано прогоном: запрос от несуществующего тенанта вернул чужие чанки KBTU. `stores.py:97-99` занижает, но не исключает; финальная сборка `:116-123` не перепроверяет tenant. Нарушает инвариант §2.4 (риск №1 проекта). Невидим в однотенантной БД — потому опасен.
2. **🟡→P1 OCR-календари структурно повреждены.** `paragraph=False` + построчный join перемешивает колонки семестров → даты сессий/каникул рискуют привязаться не к тем событиям. Это самый дато-чувствительный и вредоносный класс ошибки.
3. **🟡→P1 8 битых чанков** (`<mark`-половинки + U+FFFD): token-window режет по токенам, повреждая теги и UTF-8-символы на границах. Мусор в эмбеддингах и цитатах.
4. **⚠️→P1 46 чанков-дублей колонтитулов (8.7%)** проходят фильтр и загрязняют top-k.

## Решения, из-за которых проект трудно масштабировать

1. **git отсутствует** — нет истории/отката/CI. Блокер для командной работы и любой дисциплины.
2. **Кириллический путь репо** — уже ломал EasyOCR; сломает Docker/CI. Переезд на ASCII дёшев только до git init.
3. **Дрифт `00-foundation` от кода** (парсер, эмбеддинги, стор, структура §13, токенайзер §14) — младшая модель, следуя доку, «починит» работающее или уйдёт в несуществующие файлы.
4. **Мёртвый ключ `embedding.profile: cloud`** в YAML при индексе 384 — переиндексация «по конфигу» молча сломает инвариант §2.10.

## Уже реализуется, но НЕ нужно для первого MVP

1. **Движок B (рекомендатель грантов)** — зрелый POC, но это отдельный продукт. Для MVP «ассистент одного вуза» он не нужен; см. `docs/02_Product_Strategy` (решение о маршруте — за владельцем).
2. **pgvector прод-путь** — писать код прода до работающего локального MVP преждевременно; SQLite-демо достаточно до пилота.
3. **Postgres для движка B** — не нужен, пока движок B не выбран основным продуктом.

## Отсутствует, без чего нельзя безопасно показывать пользователям

1. **Слой генерации (LLM) + guardrails + отказ** — сейчас продукт возвращает чанки, а не ответы. Без anti-hallucination показывать «ответы» пользователю нельзя.
2. **UI** — нет интерфейса вообще.
3. **Логирование запросов** — без него нельзя отлаживать галлюцинации и доказывать качество.
4. **Исправление утечки тенанта** — до любого мультивузового показа.
5. **Убрать ложную строку «сверка с adilet»** из питча движка B — продукт про честность не может заявлять верификацию, которой нет (`pitch:306`, README:9).

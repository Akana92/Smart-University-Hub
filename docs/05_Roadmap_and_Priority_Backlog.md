## Правила исполнения (для младшей модели)

1. Задачи берутся ТОЛЬКО из этого бэклога, в порядке приоритетов; следующая — после сверки с roadmap.
2. Каждая задача = task-пакет `docs/tasks/TASK-XXX_*.md`; работа вне пакета запрещена.
3. После каждой задачи: список изменённых файлов → что изменено → тесты (прогнаны/описаны) → что не проверено → коммит с ссылкой на TASK-ID.
4. P2/P3-строки в MVP-фазе не трогать даже «попутно» (§9 ТЗ, docs/04 §5-правило).

# 07 — Пивот: платформа успешного поступления

> **Статус:** активный план продукта (сменяет фокус docs/06 «интеграция движков» → продукт для абитуриентов).
> Конституция — [docs/00](00-foundation.md) (ADR-022). Курсовая часть (ТЗ) сдана и НЕ ломается.

## 1. Позиционирование (одним абзацем)

**Не «ассистент студофиса KBTU», а платформа успешного поступления.** Абитуриент за ~год до поступления
получает **персональную дорожную карту**: что собрать, к каким баллам готовиться, какие сроки, где и как
готовиться (курсы), и **в любом случае получает ответ** от ИИ-советника. Реальные данные (проходные баллы,
документы, сроки) + человеческие советы. Дальше — все вузы РК, потом помощь с поступлением за рубеж.

## 2. Аудитория и монетизация

- **Аудитория:** абитуриенты РК (11 класс/выпускники), их родители; позже — те, кто целится за рубеж.
- **Монетизация — реклама** в «Гиде абитуриента»: подготовительные курсы, репетиторы, языковые школы,
  профильные компании. Рекламный слот = нативная карточка «где подготовиться» в нужном шаге дорожной карты.
  **Факт-рекомендация (баллы/куда пройдёшь) НЕ продаётся** (этика, docs/02) — продаётся присутствие в подготовке.
- Позже: B2B вузам (лиды/присутствие), премиум-функции (сравнение, зарубеж-трек).

## 3. Что меняется и что переиспользуем

| Было (курс/интеграция) | Стало (продукт) |
|---|---|
| Ассистент студофиса KBTU, строгий отказ «кабинет 101» | **ИИ-советник абитуриента** — помогает всегда (см. §5) |
| Один вуз (KBTU) | **Мультивуз:** KBTU + КазНУ + Nazarbayev (→ все РК → зарубеж) |
| Навигатор грантов (есть) | Остаётся как раздел |
| Клик-FAQ (есть) | Встраивается в разделы |
| Непонятно «о чём сайт» | **Разделы** — сразу понятно, зачем платформа (§4) |

**Переиспользуем всё:** мультитенант (`tenant_id`=вуз уже в коде, §2.4), RAG+цитаты, навигатор (движок B, 87 вузов
по баллам), клик-FAQ, гибрид retrieval, оценка Ragas. Ничего не выбрасываем — **переупаковываем и расширяем**.

## 4. Информационная архитектура (разделы)

| Раздел | Задача (что человек «тыкает и понимает») | Данные | Монетизация |
|---|---|---|---|
| 🎯 **Гид абитуриента** | дорожная карта за год: с чего начать → документы → к каким баллам готовиться → сроки → **где готовиться (курсы)** → советы ИИ | общий процесс поступления РК + данные вузов | **рекламные слоты курсов/репетиторов** |
| 🏛️ **Университеты** | выбрал вуз → всё по нему: о вузе, программы, поступление (документы/баллы/модель), студжизнь, гранты | per-вуз (KBTU/КазНУ/NU): PDF+веб → RAG | — |
| 📊 **Навигатор грантов** | балл ЕНТ + предметы → куда проходишь на грант (есть) | движок B (87 вузов, баллы 2025) | — |
| ⚖️ **Сравнить вузы** | «сравни KBTU и КазНУ по IT-грантам / стоимости / студжизни» | LLM по векторной базе (нужен **GraphRAG**) | премиум позже |
| 🤖 **AI-ассистент** | любой вопрос абитуриента → полезный ответ (советник, не отказ) | RAG по всем вузам + общие знания (§5) | — |

Навигация вверху: понятная, 5 разделов, каждый — с одной ясной пользой. Мобайл-first.

## 5. Ассистент-советник (фикс «не отказывать»)

Ревизия строгого context-only (§9.2) **для продукта** (курсовой строгий режим сохраняем флагом — §7):

**Три уровня ответа:**
1. **Общий совет по поступлению** («с чего начать», «какие документы обычно нужны», «как готовиться к ЕНТ»)
   → отвечает по существу (общеизвестный процесс поступления РК), ясно и по-человечески. Это ценность платформы.
2. **Конкретный факт вуза** (проходной на ГОП, сроки, перечень документов конкретного вуза, стоимость)
   → **только из базы/навигатора с указанием источника**. Не выдумывать числа.
3. **Нет точных данных** → мягко: «точные данные по X уточняются — вот где посмотреть/куда обратиться»,
   БЕЗ тупикового «кабинет 101». Предложить смежное, что платформа знает.

**Инвариант безопасности:** общие советы — можно из знаний модели; любые ЧИСЛА/сроки/требования конкретного
вуза — только из данных с провенансом. Галлюцинация факта об абитуриенте недопустима (цена ошибки — судьба).

## 6. Мультивуз

- **Config-driven per вуз** (как `configs/kbtu.yaml`): `kaznu.yaml`, `nu.yaml`. Свой `tenant_id`, свой корпус
  (PDF правил приёма/академполитики + веб-страницы). Индекс — тот же pgvector, фильтр по `tenant_id`.
- **KBTU** — готов. **КазНУ** — крупнейший, ЕНТ/грант, много открытых данных, консистентен с навигатором.
  **Nazarbayev University** — своя модель (англ., собственный отбор, foundation) → раздел-витрина «зарубеж-стиль».
- Навигатор грантов уже покрывает 87 вузов по баллам; разделы «Университеты» — глубокая инфа по 3 избранным.

## 7. Копирайтинг (анти-ИИ-слог)

Проблема: генеренный ИИ-текст утомляет, читается как «писал бот» → теряем доверие/удержание.
**Все пользовательские тексты (заголовки, подводки, CTA, карточки) — через копирайтинг-пасс** (маркетинг-агент):
- конкретика вместо общих слов; выгода абитуриента первой строкой; голос «свой человек, который прошёл это»;
- боль аудитории (тревога поступления) → ясное обещание; без канцелярита и ИИ-штампов;
- казахстанский контекст (ЕНТ, гранты, ГОП). Красные пометки владельца на скринах — переписать в первую очередь.

## 9. Бюджет и риски

- **OpenAI:** остаток ~$4.2 из $5. Разделы/советник/тексты — почти бесплатны в рантайме (клик-слой 0 токенов).
  Заметные разовые траты: GraphRAG-построение и переиндексация +2 вузов (эмбеддинги) — предупрежу до траты.
- **Риск галлюцинации факта** (советник) — жёсткий инвариант §5: числа/сроки только из данных с источником.
- **NU иная модель** — не ломать навигатор (ЕНТ-грант); NU-раздел подаёт как отдельный трек.
- **Курс не ломается:** строгий режим ассистента и KBTU-демо сохраняются (флаг), защита возможна на закоммиченном состоянии.

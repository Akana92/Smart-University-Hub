# 08 — Отчёт к защите

> Итоговый документ проекта **Smart University**. Курсовая часть (ТЗ) сдана полностью; поверх неё
> построен продукт — платформа успешного поступления. Конституция и решения — [docs/00-foundation](00-foundation.md).

## 1. Что сделано (в двух предложениях)

Построен production-ready RAG-ассистент по официальным документам вуза (движок A) с защитой от
галлюцинаций, кликабельными цитатами и оценкой через Ragas — **все 5 этапов ТЗ**. Затем проект развит
в монетизируемую **платформу абитуриента**: 5 разделов, 3 вуза (KBTU/КазНУ/NU), навигатор грантов,
сбалансированное сравнение вузов и AI-советник — с токен-экономной 2-слойной архитектурой, трёхъязычным
интерфейсом и ответами (RU/KK/EN), памятью диалога и приватной админ-панелью наблюдаемости.

## 2. Соответствие ТЗ (курсовая часть)

| Требование ТЗ | Реализация | Где |
|---|---|---|
| **Ingestion**: PDF, таблицы → Markdown, семантический чанкинг 500–1000 ток, overlap 10–15%, метаданные (источник/категория/страница) | pymupdf4llm page-aware; **таблица = атомарный чанк**; structure-aware (заголовки + token-window 700/overlap 90, tiktoken cl100k); метаданные §6.1 + провенанс | `ingestion/ingest.py`, `ingest_web.py` |
| **Retrieval**: вектор-БД, гибрид семантика + BM25, фильтр по метаданным | **pgvector** dense `<=>` + Postgres **FTS(`russian`) BM25** + **RRF в SQL**; фильтр по `category` и `tenant_id` | `retrieval/stores.py` |
| **Generation**: LlamaIndex/LangChain, анти-галлюцинация, **дословный отказ**, Streamlit, **кликабельные цитаты** (документ+страница) | LlamaIndex + gpt-4o-mini (temp 0); 3 рубежа (см. §4); дословный отказ «…кабинет 101» (strict); Streamlit + новый веб-UI; цитаты из метаданных | `generation/`, `api/main.py`, `ui/` |
| **Тестирование через Ragas** | golden set 73, RAG-триада (faithfulness/relevancy/precision/recall), **судья ≠ генератор**, отчёт + гейт | `eval/run_ragas.py`, `eval/gate.py` |

## 3. Архитектура

**Два движка** (ADR-014): A — RAG по текстам (семантика), B — навигатор по числам (детерминированный SQL).
Числа не доверяются LLM — цена ошибки для абитуриента слишком высока.

**Два слоя** (ADR-021, токен-экономия):
- **Слой 1 (0 токенов):** навигатор грантов (SQL) + клик-FAQ (18 готовых карточек). Массовый трафик.
- **Слой 2 (LLM):** AI-советник (движок A) — только «длинный хвост». Единый роутер `/v1/ask` разводит интент.

**Гибридный retrieval:** dense (pgvector, OpenAI 3072, HNSW на halfvec — обход лимита 2000 dim) +
lexical (tsvector/ts_rank) + RRF (K=60) одним SQL-запросом.

**Мультивуз:** один индекс, `tenant_id`=вуз (652 чанка). Поиск по всем (`None`) или по выбранному;
append-индексация добавляет вуз без сброса чужих.

**Мультиязычность (RU/KK/EN, TASK-030):** язык ответа советника — по языку сообщения (детектор `core/lang.py`,
0 токенов); интерфейс, FAQ и карточки вузов локализованы (`?lang=`); строгий режим по ТЗ остаётся русским.

**Память сессии + фокус вуза (TASK-030/033):** прошлые ходы диалога подмешиваются настоящими репликами
(окно 2 обмена); вуз в фокусе диалога определяется из истории и сужает поиск — follow-up не перескакивает.
Сравнение вузов идёт сбалансированным ретривалом по всем + справка из реестра (плюсы/минусы по каждому).

**Наблюдаемость (TASK-031):** приватная админка `/admin` (гейт `ADMIN_TOKEN`) над JSON-логом: история
запросов, прочитанные чанки со скорами/рангом, токены, latency, здоровье БД и движков.

## 4. Три рубежа защиты от галлюцинаций

1. **Pre-LLM confidence gate** (strict): нет релевантных чанков → дословный отказ **без вызова LLM** (бережёт ключ).
2. **Context-only промпт**: модель обязана ответить шаблоном отказа, если ответа нет в контексте.
   В режиме advisor — общий совет допустим, но **конкретные числа/сроки вуза — только из контекста**.
3. **Цитаты только из метаданных** найденных чанков (source_nodes), не из текста модели.

## 5. Метрики (Ragas, судья gpt-4o ≠ генератор gpt-4o-mini)

| Метрика | Значение | Смысл |
|---|---|---|
| **Faithfulness** (по отвеченным) | **1.00** | галлюцинаций нет — главный приоритет ТЗ |
| Context precision / recall | 0.93 / 0.78 | retrieval поднимает релевантное, покрывает эталон |
| Answer relevancy | 0.79 | ответ по существу |
| **Refusal rate** (вне базы) | **1.0 (16/16)** | корректно отказывается, когда данных нет |

Оси разделены (faithfulness — по отвеченным, refusal — отдельно). Гейт `eval/gate.py` роняет билд при
просадке ниже baseline (`eval/baseline.json`). Герметичный набор `pytest` = **71 passed** (без БД/ключа).

## 6. Продуктовый пивот (goal №2)

После сдачи ТЗ проект развит в **платформу успешного поступления** (ADR-022, [docs/07](07_Applicant_Platform_Pivot.md)):
ассистент из «студофиса KBTU» стал **советником абитуриента** (помогает, не отказывает шаблоном);
добавлены разделы (Гид/Университеты/Навигатор/Сравнить/Ассистент), мультивуз (КазНУ+NU), рекламные
слоты в Гиде (монетизация), человеческий копирайтинг. Отдельным исследованием подтверждено: **GraphRAG
не экономит токены** на нашем масштабе — сравнение вузов сделано дешевле (SQL + таблица). Дополнительно:
трёхъязычность RU/KK/EN (ответ на языке сообщения), память диалога с удержанием контекста вуза, сбалансированное
сравнение (плюсы/минусы по всем вузам, без отфутболивания наружу) и приватная админ-панель наблюдаемости.

## 7. Структура презентации (слайды)

1. **Проблема** — абитуриент теряет год: непонятно, куда пройдёт, что собирать, как готовиться.
2. **Решение** — платформа: план за год + реальные баллы + советник, всё в одном.
3. **Демо** (см. §8) — навигатор → FAQ → советник → мультиязычность → память/контекст → сравнение → отказ → /admin.
4. **Архитектура** — 2 движка × 2 слоя (диаграмма §3), гибридный RAG.
5. **Анти-галлюцинация** — 3 рубежа + метрики Ragas (faithfulness 1.0, refusal 1.0).
6. **Токен-экономика** — 80% запросов без токенов (Слой 1); почему это монетизируемо.
7. **Мультивуз + масштаб** — 3 вуза сейчас → все вузы РК → зарубеж; append-индексация.
8. **Монетизация** — рекламные слоты курсов в Гиде; факт-рекомендация не продаётся (этика).
9. **Инженерия** — тесты (71 герметичный), judge-гейт, CI, честные инварианты данных, приватная админ-панель
   наблюдаемости (какие чанки читает LLM, скоры/ранг, токены, здоровье).

## 8. Демо-сценарий (проверено вживую)

Открыть **http://localhost:8000**. Порядок — от бесплатного к «умному»:

| # | Действие | Ожидаемо |
|---|---|---|
| 1 | Навигатор: балл **104**, профиль **физика + математика**, «Подобрать» | **207 проходят / 2 на грани / 13 не хватает**, карточки инженерных ГОП с проходным+источником (0 токенов) |
| 2 | Клик-FAQ: «Как рассчитывается GPA?» | мгновенный ответ + ссылка на источник (0 токенов) |
| 3 | Ассистент: «Можно ли пересдать экзамен, если получил FX?» | ответ + **цитата КС ИСМ КБТУ 51-2-25 · стр. 16** (движок A) |
| 4 | Мультиязычность: спросить **по-казахски** «Грантқа қалай түсуге болады?» | ответ **на казахском**; переключатель RU/KK/EN меняет весь интерфейс + FAQ + карточки вузов |
| 5 | Память/контекст: выбрать **NU** → следом «а студенческая жизнь?» | ответ **остаётся про NU**, не перескакивает на KBTU — контекст диалога держится |
| 6 | Сравнить вузы (или спросить ИИ «сравни KBTU, КазНУ, NU») | **плюсы/минусы по КАЖДОМУ** вузу + рекомендация под профиль; сбалансированные цитаты, без «идите на сайт вуза» |
| 7 | Ассистент: «Какая погода завтра?» / выдуманный факт вуза | мягкий возврат к теме / «нет точных данных по этому вузу» — **без выдумок** |
| 8 | «Куда пройду со 104 баллами, хочу в IT» | ассистент **сам** подбирает IT-программы инлайн, не перенаправляет |
| 9 | Открыть **/admin** | история запросов LLM: прочитанные чанки со **скорами/рангом**, токены, latency, здоровье БД/движков |

**Упаковка (Docker).** Весь стек — `docker compose up -d --build`: Postgres/pgvector с уже загруженным
индексом из `db/seed` (без переиндексации) + приложение на :8000. Образ рантайма тонкий (~402 МБ,
`requirements-app.txt` — только сервинг). Тяжёлые библиотеки полного пайплайна — **pymupdf/easyocr+torch**
(парсинг и OCR при индексации), **sentence-transformers** (локальный эмбеддер), **Ragas+LangChain** (оценка),
**Streamlit** (UI этапа 4) — остаются в `requirements.txt`, использовались на своих стадиях и в прод-образ не
тянутся; их результаты (индекс, отчёт Ragas, judge-гейт) уже в репозитории. Без ключа работают
навигатор/FAQ/вузы/сравнение, ключ включает AI-советника.

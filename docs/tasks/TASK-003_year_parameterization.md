# TASK-003 — Параметризация года данных (убрать хардкоды 2025)

**Цель.** Августовское обновление на итоги-2026 должно прогоняться без правки кода. Сейчас год зашит в трёх местах.

**Связанный пункт ТЗ:** DR-1 (docs/03_ §8); арх. A3 (docs/04 §5).

**Контекст (точные места, выверены аудитом и критиком):**
- `poc/grant-recommender/scrape_all.py:27` — `YEAR = 2025`.
- `poc/grant-recommender/scrape_univision.py:29` (константа) и `:106` (использование) — третий хардкод, найден критиком, в первой версии DR-1 отсутствовал.
- `poc/grant-recommender/recommend.py:80` — литерал `p.year=2025` в SQL.
- Страницы univision помечены «(2025)»: скрейперы её только МАРКИРУЮТ; `--year` задаёт, каким годом подписывать собранное (сайт отдаёт актуальный срез). Это поведение задокументировать в help-тексте аргумента.

**Границы.** Только замена констант на CLI-аргументы + дефолты + тесты. Логику скрейпинга/расчёта не менять.

**Запрещено менять:** эвристики `classify()`/`nearest_label()` (это RB-201), схему БД, консервацию §9 ТЗ, P2/P3-области.

**Файлы можно менять:** `scrape_all.py`, `scrape_univision.py`, `recommend.py`, `api/main.py` (если прокидывается год в engine_b), `tests/test_year_param.py` (новый), README POC.

**Ожидаемый результат.**
- `python scrape_all.py --year 2026` / `python scrape_univision.py --year 2026` — работают, год попадает в каждую строку CSV.
- `recommend.py`: дефолт = **максимальный год, присутствующий в БД** (`SELECT MAX(year) …`), опциональный `--year` для override. Это защищает от молчаливого показа 2025 после загрузки 2026 (находка аудита).

**Критерии приёмки.**
1. `grep -rn "2025" poc/grant-recommender/*.py` не находит год в ЛОГИКЕ (допустим только как default-значение argparse с комментарием «последний полностью распределённый конкурс» — а для recommend дефолт вычисляется из БД, не константой).
2. `recommend.py --score 100 --profile "математика,информатика"` даёт тот же результат, что до правки (регресс на данных 2025).
3. `python -m api.test_api` — ALL PASS без изменений тестов.

**Тесты.** `tests/test_year_param.py`: recommend с мини-БД, где есть годы 2025 и 2026 → без `--year` берётся 2026; с `--year 2025` — 2025.

**Definition of Done.** Критерии 1–3; весь `pytest tests -q` зелёный; коммит `TASK-003: ...`.

**Как проверить.** Команды из критериев + diff вывода recommend до/после.

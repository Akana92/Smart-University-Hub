# POC — Рекомендатель грантов (движок B)

Доказательство **самой рискованной части** платформы (см. [docs/03 §4–5](../../docs/03-multi-university-recommender-strategy.md)): можно ли **реально** собрать точные данные о проходных баллах на грант и построить рекомендацию «куда пройду».

**Ответ: да.** Пайплайн собрал живые данные по **87 вузам** (5632 строки), выдаёт объяснимую рекомендацию с провенансом, обёрнут в **FastAPI** (Postgres-готов) и **интерактивный питч-артефакт** (`pitch/grant-navigator.html`).

## Что доказано
- ✅ Проходные баллы **скрейпятся** с `univision.kz` в структурированный вид (**5632 строки, 87 вузов** — все, у кого есть страница баллов).
- ✅ Данные **внутренне согласованы**: КазНУ B057 ИТ = 90 баллов / 115 грантов; B050 Биология = 81/551; B085 Фармация = 124/1; BM086 Медицина = 119 — два независимых способа чтения **одного и того же источника** (скрейпер и ручная выборочная проверка страниц univision) дали одинаковые числа. ⚠️ Это подтверждает корректность скрейпинга, но НЕ независимую верификацию данных: **сверка с официальным adilet/testcenter не выполнена** (запланирована, см. «Что дальше»).
- ✅ Рекомендатель раскладывает программы на **✅ проходит / ⚠️ рискованно / ❌ не проходит** по баллу + профильным предметам, с порогом допуска и **провенансом** (источник, год, число грантов, достоверность).
- ✅ Числа **только из БД** (движок не выдумывает баллы) + честная оговорка «не гарантия».

## Как запустить
```bash
pip install -r requirements.txt

python scrape_all.py           # 1) собрать баллы по ВСЕМ 87 вузам (~2-3 мин, вежливо)
python build_db.py             # 2) SQLite grant_scores.db (+ таблица tuition)
python recommend.py --demo     # 3) CLI-демо: 3 профиля абитуриентов

# произвольный запрос (+ бюджет → ветка «не хватило → платное»):
python recommend.py --score 60 --profile "история,основы права" --budget 3000000

# API (движок B + заглушка движка A под единым FastAPI):
python -m api.test_api         # смоук-тесты (TestClient) — все PASS
uvicorn api.main:app --reload  # http://127.0.0.1:8000/docs

# интерактивный питч: pitch/grant-navigator.html
```

## Данные и провенанс
- **Источник баллов:** `univision.kz` — агрегатор (`source_type=aggregator`, `confidence=medium`). НЕ официальный первоисточник → в проде обязательна сверка с `adilet` (объёмы грантов) и `testcenter` (пороги). См. docs/03 §3.
- **Год:** 2025 (последний полностью распределённый конкурс). Каждая запись несёт `source_url + year + scraped_at`.
- **Вежливость:** UA с контактом, задержка 2 сек, только разрешённые `robots.txt` пути (`/univ/.../ball`).

## Ограничения (честно)
1. **Историческая отсечка ≠ гарантия.** Проходной 2026 формируется постфактум. Показываем 2025 как вероятность.
2. **Гранулярность — ГОП, не специальность.** Конкурс идёт по группам образовательных программ (B###).
3. **`profile_map.json` иллюстративен** — матчинг по ключевым словам названия ГОП; канонический перечень «профиль→ГОП» берётся из приказа adilet V1700015186.
4. **Пороги упрощены** до статутных национальных правил (50/65/70/75); в проде — точная привязка по ГОП.
5. **87 вузов** собрано (все, у кого есть страница `/ball` на univision); часть вузов страницы баллов не имеет.
6. **Только общий конкурс** в демо-рекомендации (квоты собраны в БД: rural/disability/large_family/single_parent, но в выдаче пока не используются).
